After Effects Motion Rig

Scripting After Effects instead of clicking it

Built

This is a scripted motion system for After Effects that replaces manual GUI work with a headless render pipeline. It uses ExtendScript JSX and aerender to drive a shared design-token layer, a kinetic-typography engine, and a spatial type library, allowing for precise control over complex animation sequences that are difficult to manage by hand.

The problem

Manual animation in After Effects is slow and prone to inconsistency. Complex kinetic typography, such as 3D-faked extrusion or multi-layered text, requires precise control over layer stacking and camera transforms that the standard GUI cannot reliably maintain. Without a programmatic approach, managing thousands of layers or complex render stacks leads to visual artifacts and wasted render time. The lack of native motion blur in some 3D renderers further complicates the production of high-quality motion assets.

What I built

The system successfully automates complex motion sequences, including a 10,000-layer kinetic-type experiment. It is not without limitations; the faked extrusion method causes slices to comb apart at extreme yaw angles. A configuration bug in the layer spec nesting once caused 240 pure-white frames, and incorrect glow settings previously blew out highlights. These issues are now tracked and mitigated through schema validation and strict framing rules.

How it works

The system uses a configuration-driven architecture where JSON files define the motion, which is then executed by ExtendScript JSX scripts. For 3D effects, I implemented a faked extrusion method using stacked 2D layers rather than the cinema4d renderer, which lacks motion blur. I also built a kinetic-typography engine with 105 graded techniques. The pipeline includes a verification step to catch configuration errors before rendering, ensuring that layer specifications are correctly nested and parameters remain within safe bounds.
