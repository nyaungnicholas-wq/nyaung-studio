Discipline Reels

A specified visual language for vertical short-form

Built

Discipline Reels is a repeatable system for creating faceless, cinematic vertical shorts that pair disciplined-themed speech with dark b-roll, a swelling orchestral bed, and synchronized karaoke captions. It defines a fixed visual-caption language so each reel can be produced by swapping data rather than building from scratch.

The problem

Creators struggle to make discipl-themed motivation reels at scale because extracting usable speech from YouTube risks copyright strikes, manual editing is slow, and maintaining a premium cinematic look across varied free clips is hard without a consistent visual language. The result is either low-quality, legally risky content or a bottleneck that prevents regular posting, hurting algorithmic growth and audience retention.

What I built

To date the project has produced the complete super prompt, this operating guideline, the competitor-intelligence report, and the exact audio-pipeline design (yt-dlp, ffmpeg, faster-whisper commands). The three automation scripts and the locked Remotion template (CinematicDisciplineV1.tsx) are still to be built; once finished the workflow will reduce to paste-link-and-render. No performance metrics have been measured yet because the rendering engine is not complete.

How it works

The workflow starts by pasting a YouTube URL and selecting a 22–40s peak segment; yt-dlp extracts the audio and ffmpeg converts it to wav. faster-whisper produces word-level timing JSON, which is cleaned of filler words. In SAFE mode the transcript is re-voiced with ElevenLabs, then re-timed for tight karaoke. A hook is scored ≥14/18 using the super-prompt rubric, the turn and resolve lines are identified, and a 70–100 BPM royalty-free cinematic bed is chosen. Real-footage b-roll is fetched via node script, a call-out table maps each beat to visuals, transitions, music and captions, the data stamps the locked Remotion template, and the render is QA-checked on tentpole frames before posting.

Shot length, caption cadence and speech timing fixed as parameters rather than taste

Highlights

  • The pipeline extracts audio with yt-dlp and ffmpeg, then transcribes it word-by-word using faster-whisper.
  • In SAFE mode the cleaned transcript is re-voiced with an ElevenLabs cinematic voice to avoid copyright claims.
  • Music beds are royalty-free cinematic tracks at 70–100 BPM that swell under the resolving line for emotional payoff.
  • All visuals are real footage only—no AI-generated faces—to prevent reach-penalty flags on platforms.
  • Each reel uses a single serif key line with one imperfect hand-drawn mark as the sole human touch.
  • The final render is a seamless 1080×1920 loop at ~−14 LUFS, cross-posted to Instagram Reels and TikTok.
